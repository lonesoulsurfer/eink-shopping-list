Install the E-Ink Shopping List Board

Install the firmware straight from this page. No Arduino IDE, no libraries and no settings to get right. Firmware version 1.0.0.

You'll need

  • A LILYGO T5 4.7" E-Paper, ESP32-S3 touch version ("T5-4.7-S3").
  • A computer with Chrome or Edge. Safari, Firefox and phones can't do this.
  • A USB-C cable that carries data, not just power.
This browser can't install firmware. Please open this page in Chrome or Edge on a computer. Installing needs a secure page. Open this page from its https:// address.

Installed

Now unplug the board and plug it back in (don't hold any buttons this time). The screen won't change until you do.

Steps

  1. Hold down the BOOT button (the middle button on the board) while you plug the board into your computer with the USB-C cable, then let go. This puts the board into install mode. Without it, the board usually won't show up in the list.
  2. Click Install, then choose the board in the list that pops up (it's usually called "USB JTAG/serial debug unit" or shows a COM port), and click Connect.
  3. Click Install E-Ink Shopping List Board.
  4. You'll be asked about erasing the device:
    • First time installing on this board: tick Erase. It clears out whatever was on the board before.
    • Updating a board that's already running the shopping list: leave Erase unticked, or you'll lose your list, WiFi and email settings.
  5. Wait about a minute. When it's done, the installer window closes by itself and a green Installed box appears on this page. Then unplug the board and plug it back in to start it.
After a first install the screen shows "Setup needed". Scan the QR code on the screen with your phone (or join the WiFi network ShoppingList-Setup) and enter your home WiFi. The full guide covers the rest.

If something goes wrong

  • The board isn't in the list ("No compatible devices found"), or it says "Failed to initialize": unplug the board, hold the BOOT button (the middle one) while plugging it back in, let go, then click Install again. Still nothing? Flip the USB-C plug over, try another USB port on the computer, or try another USB-C cable. Some cables only carry power.
  • The screen doesn't change after installing: unplug the board and plug it back in.
  • It sits on "Wrapping up" for more than a minute: the firmware is already installed by then. Close the window, then unplug the board and plug it back in.
  • "Failed to open serial port": close the Arduino IDE or anything else that might be using the board, then try again.

Want to change the code?

All the source code is on GitHub, with instructions for building it yourself in the Arduino IDE. The full build guide is on Instructables.

The installer uses ESP Web Tools. The firmware includes the GPL-3.0 licensed LilyGo-EPD47 display library; its source is linked from the GitHub page.
